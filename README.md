# Waveshare ESP32-P4-WIFI6-Touch-LCD-X Product Engineering Sample Program

This series of products is a high-performance development board based on the ESP32-P4 chip, featuring a dual-core and single-core RISC-V architecture. It is equipped with 7 / 8 / 10.1-inch IPS touch screens and supports a variety of human-machine interaction interfaces.
